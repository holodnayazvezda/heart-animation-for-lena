# heart-animation-for-lena

Персональная веб-страница с анимацией сердца, текстом и изображениями. Сервер написан на Flask, оформление находится в HTML-шаблонах.

## Запуск

```sh
python -m pip install flask
python main.py
```

Откройте `http://localhost:8080/4u`. Изображения лежат в `static/images/`, основной шаблон — `templates/index-with-text.html`.
